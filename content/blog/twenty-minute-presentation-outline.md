20분 발표를 준비한다면 원고를 길게 쓰기 전에 **구간별로 무엇을 설명하고 언제 끝낼지**부터 정해보세요. 한 가지 제안을 문제, 해결 방법, 실행 계획으로 나누면 자료와 대본을 배치하기 쉬워요.

아래에서는 "회의 후 할 일을 공동 문서에 남기자"는 가상의 개선안을 예시로 사용할게요. 시간표는 20분 안에서 설명하기 위한 배분안이며, 실제 발표를 측정한 결과는 아니에요.

## 먼저 20분에 무엇이 포함되는지 확인하세요

본 발표만 20분인지, 질의응답과 시연까지 합쳐서 20분인지에 따라 쓸 수 있는 시간이 달라져요. 발표 안내에서 이 부분을 먼저 확인하세요.

이 글의 첫 시간표는 **질의응답을 제외한 본 발표 20분**을 가정해요. 질의응답까지 포함되는 경우의 배분안은 뒤에서 따로 볼게요.

대본 글자 수부터 계산하고 싶다면 [발표 시간별 분량과 계산 예시](/blog/presentation-script-length)를 참고하세요. 이 글에서는 내용을 어떤 순서로 나눌지에 집중해요.

## 20분 발표 시간 배분표

문제 설명에 4분, 제안에 6분, 실행에 4분을 배정했어요. 도입과 마무리는 각각 2분, 화면 전환이나 예상보다 길어진 설명을 위한 여유는 2분으로 잡았어요.

| 구간 | 배정 시간 | 전달할 내용 | 끝내기 목표 시점 |
| --- | --- | --- | --- |
| 도입 | 2분 | 문제와 발표의 결론 예고 | 2분 |
| 문제 | 4분 | 현재 방식에서 생기는 어려움 | 6분 |
| 제안 | 6분 | 바꿀 방식과 구체적인 예시 | 12분 |
| 실행 | 4분 | 적용 범위, 담당자, 확인 방법 | 16분 |
| 마무리 | 2분 | 제안 요약과 요청 | 18분 |
| 여유 | 2분 | 전환, 멈춤, 설명 지연에 활용 | 제한 20분 |

목표 시점은 여유 시간을 쓰지 않았을 때의 기준이에요. 여유 2분은 마지막에 따로 침묵하는 시간이 아니라 발표 중 필요한 곳에 쓰는 시간이에요.

## 도입 2분: 무엇을 결정하면 되는지 알려주세요

주제와 관련된 넓은 배경을 모두 설명하기보다, 듣는 사람이 겪었을 법한 장면 하나로 시작해보세요. 이번 예시에서는 회의가 끝났는데 다음 할 일이 분명하지 않은 상황을 보여줄 수 있어요.

> "회의에서 방향은 정했는데, 며칠 뒤 누가 무엇을 하기로 했는지 다시 확인한 적이 있을 겁니다. 오늘은 회의가 끝날 때 담당자와 다음 행동을 공동 문서에 남기는 방법을 제안드리겠습니다."

이어서 문제, 제안, 실행 순서로 설명하겠다고 안내해요. 듣는 사람이 발표 전체의 목적과 이동 경로를 먼저 알게 하는 단계예요.

## 문제 4분: 비슷한 사례를 늘리지 말고 하나를 보여주세요

한 회의를 가정하고 회의 직후부터 다음 회의까지 무엇이 엇갈렸는지 설명해보세요. "자료를 보완하자"고 정했지만 담당자와 전달 시점을 정하지 않은 상황처럼 구체적이면 좋아요.

실제 조사나 기록이 있다면 범위와 출처를 밝혀 사용하세요. 자료가 없다면 "대부분의 회사가 그렇다"고 일반화하거나 임의의 비율을 만들지 말고, 설명용 가상 사례라고 밝혀요.

이 구간에서는 문제가 있다는 것과 왜 바꿔야 하는지를 이해시키면 돼요. 같은 유형의 사례 세 개를 연이어 말할 필요는 없어요.

### 문제에서 제안으로 넘어가는 요약

> "지금까지 본 문제는 결정한 내용보다, 그다음 행동이 불분명하다는 점입니다. 이제 회의가 끝날 때 무엇을 남기면 좋을지 말씀드리겠습니다."

앞의 사례를 다시 설명하지 않고, 핵심 문제와 다음 질문만 연결해요.

## 제안 6분: 화면 한 장을 실제로 채워보세요

공동 문서에 남길 항목을 결정 사항, 담당자, 다음 행동, 확인 시점으로 정했다고 해볼게요. 이름만 나열하지 말고 회의 예시 하나를 넣어 각 칸을 채워보세요.

| 항목 | 작성 예시 |
| --- | --- |
| 결정 사항 | 다음 안내문에는 준비물을 별도 항목으로 표시 |
| 담당자 | 안내문 수정 담당자 |
| 다음 행동 | 수정 초안을 작성해 팀에 공유 |
| 확인 시점 | 다음 주 화요일 회의 전 |

이 표는 가상의 작성 예시예요. 실제 적용할 때는 "담당자"라는 역할명 대신 누가 맡았는지 알아볼 수 있게 적어야 해요.

설명할 때는 각 항목이 빠지면 어떤 질문이 남는지 보여주세요. 다음 행동은 있지만 담당자가 없으면 누가 시작할지 모른다는 식이에요.

화면 시연을 넣는다면 이 6분 안에 포함해서 연습하세요. 설명 6분을 채운 뒤 시연을 추가하면 계획한 시간을 넘기게 돼요.

### 제안에서 실행으로 넘어가는 요약

> "핵심은 회의록을 더 길게 쓰는 것이 아니라, 다음 행동을 누가 언제 할지 남기는 것입니다. 이제 실제로 적용할 때 번거로움을 어떻게 줄일지 보겠습니다."

듣는 사람이 제안의 핵심을 한 번 정리하고 실행 조건으로 넘어가게 해주세요.

## 실행 4분: 작은 적용 범위와 확인 방법을 정하세요

모든 회의에 바로 도입하기보다, 다음 정기 회의 몇 차례에 적용해보는 안을 설명할 수 있어요. 아래 항목은 실행 계획을 만들기 위한 예시예요.

- **적용 범위:** 할 일을 결정하는 정기 회의에 먼저 사용해요.

- **기록 방식:** 회의 중에 초안을 쓰고, 끝나기 전에 담당자와 내용을 함께 확인해요.

- **수정 방식:** 일정이 바뀌면 문서를 고치고, 영향을 받는 사람에게도 알려요.

- **확인 방법:** 다음 회의에서 담당자나 기한을 다시 물어본 일이 있었는지 돌아봐요.

기록 자체가 부담이 될 수 있다는 점도 다뤄주세요. 모든 발언을 적는 대신 결정된 행동만 남기는 식으로 운영 범위를 정할 수 있어요.

### 실행에서 마무리로 넘어가는 요약

> "적용 범위는 정기 회의이고, 남길 것은 결정된 행동과 담당자, 확인 시점입니다. 마지막으로 이번에 함께 정하면 좋을 내용을 정리하겠습니다."

## 마무리 2분: 요약과 요청을 분리하세요

마지막에는 앞서 설명한 내용을 짧게 요약하고, 듣는 사람이 무엇을 해주면 되는지 말해보세요. 이때 새로운 사례나 근거를 추가하면 마무리가 다시 본론으로 길어져요.

> "회의 뒤의 혼선을 줄이기 위해 다음 행동, 담당자, 확인 시점을 같은 문서에 남기는 안을 제안드렸습니다. 다음 정기 회의부터 시험해보고, 불필요한 항목은 함께 줄이면 좋겠습니다. 오늘은 적용할 회의와 기록 담당자를 정해주시면 됩니다."

실제 요청은 발표 목적에 맞게 바꾸세요. 수업 발표라면 의사결정을 요청하는 대신, 이번 주제에서 기억할 결론을 정리할 수 있어요.

## 20분 안에 질의응답도 포함된다면

예를 들어 질의응답 5분을 확보하려면 본 발표와 전환을 합쳐 15분 이내로 준비해야 해요. 아래는 그 조건에 맞춘 별도의 배분안이에요.

| 구간 | 배정 시간 |
| --- | --- |
| 도입 | 1분 |
| 문제 | 3분 |
| 제안 | 5분 |
| 실행 | 3분 |
| 마무리 | 1분 |
| 전환과 설명 여유 | 2분 |
| 질의응답 | 5분 |
| 합계 | 20분 |

본 발표 20분짜리 원고를 빨리 읽는 방식으로 맞추지 마세요. 문제 사례를 하나로 줄이거나 시연을 짧은 화면 예시로 바꾸는 등 내용량을 함께 조정해야 해요.

## 연습할 때는 구간이 끝나는 시간을 기록하세요

총시간만 재면 어느 부분을 고쳐야 하는지 알기 어려워요. 도입, 문제, 제안, 실행이 끝날 때 각각 경과 시간을 적어보세요.

예를 들어 문제 설명을 마쳤을 때 이미 9분이 지났다면, 계획한 6분보다 3분 늦어진 상태예요. 뒤를 전부 빨리 말하기보다 문제 사례에서 어디가 길어졌는지 먼저 확인하는 편이 좋아요.

구체적으로 어떤 문장을 덜어낼지는 [발표 대본 줄이는 법](/blog/shorten-presentation-script)의 수정 전후 예시를 참고하세요. 중간에 문장이 생각나지 않을 때를 대비하려면 [발표 중 대본을 까먹었을 때 복구하는 법](/blog/presentation-script-recovery)도 도움이 될 수 있어요.

## 자주 묻는 질문 (FAQ)

### 20분 발표 PPT는 몇 장으로 만들면 되나요?

장수를 먼저 정하기보다 구간별로 어떤 내용을 보여줄지 정하세요. 한 장의 사례를 오래 설명할 수도 있고, 여러 화면을 짧게 넘길 수도 있어요. 발표 안내에 장수 제한이 있다면 그 기준을 따르세요.

### 중간 요약을 넣으면 같은 말을 반복하는 것 아닌가요?

앞의 설명을 그대로 반복하면 길어져요. 방금 구간의 결론 한 문장과 다음 구간의 질문만 연결하면, 내용을 다시 읽지 않고도 흐름을 정리할 수 있어요.

### 연습할 때마다 발표 시간이 달라져요

즉석에서 추가하는 사례나 설명이 있는지 확인해보세요. 구간마다 반드시 말할 내용과 생략할 내용을 정해두면 변동 원인을 찾기 쉬워요.

### 발표가 일찍 끝나면 내용을 더 추가해야 하나요?

요구된 내용이 충분히 전달됐다면 무조건 시간을 채울 필요는 없어요. 다만 최소 발표 시간이 정해져 있거나 설명이 빠진 부분이 있다면, 그 조건에 맞게 예시와 근거를 보완하세요.
